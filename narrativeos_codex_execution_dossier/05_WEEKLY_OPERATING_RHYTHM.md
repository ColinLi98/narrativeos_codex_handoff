# Weekly Operating Rhythm for Founder + Codex

## Monday — Ask / Plan only
- Choose the single highest-priority task
- Assign it to exactly one lane
- Write it using the issue template
- Ask Codex for implementation plan only

## Tuesday to Thursday — one narrow task per day
- Run one implementation task at a time
- Keep each task PR-sized and benchmarkable
- Require tests, docs, and benchmark / eval evidence when relevant
- Reject opportunistic scope expansion

## Friday — regression and reprioritization only
Review with these questions:
1. Did this help the current pack only, or the whole product?
2. Is there cross-pack evidence?
3. Did weakest packs improve or become easier to diagnose?
4. Did this move commercialization forward?
5. Which 1–2 lanes should be active next week?

## Monthly retrospective
Track:
- number of merged Codex PRs
- lane distribution by merged PR
- benchmark delta by pack
- weakest-pack trend
- time-to-review
- revert rate
- percentage of PRs that truly advanced commercialization
