# NarrativeOS Codex Execution Dossier

This folder contains a concrete operating kit for using Codex efficiently on the current NarrativeOS codebase.

Files:
- `00_Codex_Execution_Dossier_CN.md` — master execution dossier
- `01_AGENTS_TEMPLATE.md` — root AGENTS.md template for the repo
- `02_CODEX_ISSUE_TEMPLATE.md` — task template for Ask/Code mode
- `03_CODEX_PR_REVIEW_TEMPLATE.md` — review gate for Codex PRs
- `04_FIRST_6_TASKS.md` — the first six tasks Codex should execute
- `05_WEEKLY_OPERATING_RHYTHM.md` — weekly operating cadence for founder + Codex
- `06_RECURRING_DISPATCH_PROTOCOL.md` — canonical recurring dispatch overlay for future tasks

Recommended use:
1. Read repo-root `AGENTS.md` first.
2. Use `06_RECURRING_DISPATCH_PROTOCOL.md` as the current dispatch overlay and lane taxonomy.
3. Give Codex one task at a time using `02_CODEX_ISSUE_TEMPLATE.md`.
4. Require every PR to satisfy `03_CODEX_PR_REVIEW_TEMPLATE.md`.
5. Follow the task order in `04_FIRST_6_TASKS.md` unless the recurring protocol reprioritizes lanes.
6. Review progress weekly using `05_WEEKLY_OPERATING_RHYTHM.md`.
