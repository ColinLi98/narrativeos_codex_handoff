# Phase 2 Tasks：Author / Ops / Commercialization Skeleton

## Task 2.1：Author Draft Detail

### 目标
让 draft 不只是列表，而是可查看、可诊断、可继续完善。

### 建议改动
- Draft detail 页面
- validate / simulate 结果展示
- issue list / score / failing dimensions 展示

### 验收
- Author 可从 UI 完成 draft -> validate -> simulate

---

## Task 2.2：Asset Editors

### 目标
让普通作者不用改 JSON 也能编辑核心资产。

### 建议改动
- 角色卡编辑
- scene blueprint 编辑
- style / sensory / pacing 编辑
- diff / version history

### 验收
- 有可用 UI 主路径
- 资产改动可保存、可比较

---

## Task 2.3：Ops Review History + Publish Checklist

### 目标
让 Ops 能真实运营，而不是只看当前结果。

### 建议改动
- review history
- publish checklist
- rollback history
- quality trend drill-down

### 验收
- Ops 可查看 pack 的生命周期记录

---

## Task 2.4：Entitlement / Credits Skeleton

### 目标
为收费实验打基础，但不先做复杂支付集成。

### 建议改动
- access tier
- world pass / credits / subscription shapes
- meter -> entitlement 消耗主路径
- account ownership 预留接口

### 验收
- 后端主路径可运行
- Reader 可识别访问级别
