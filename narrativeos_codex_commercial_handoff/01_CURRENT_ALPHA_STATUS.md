# 01. 当前 Alpha 状态（整理版）

本文件整理自 `legacy/current_alpha_status.md`，作为 Codex 的当前基线输入。

## 当前已具备

- 章节化推进而不是单事件拼接
- Reader Mode 输出
- Karma Character Engine v0.1
- 因果种子、关系债、命运压力、关系图
- phase-aware 的章节推进与结局门控
- Web 前端可创建 / 恢复 / 删除 session
- 示例世界可跑，测试通过

## 当前仍不具备

- 连续 30~50 章稳定高质量文本
- 多题材、多世界稳定复用
- 完整作者工具与内容生产流
- 审核、风控、计费、资产、分析、运营面板
- 可直接上线的商业产品结构

## 当前阶段判断

推荐把当前版本定义为：

- **可运行 Alpha / 创始人原型**
- 完成度约 `25% - 35%`
- 已验证“能推进下一章”
- 尚未验证“能稳定产出值得付费的下一章”

## 给 Codex 的含义

你不是从 0 开始；你是从一个已经具备：

- 章节概念
- 因果人物逻辑
- reader 输出
- 基础测试与 API

的 Alpha 继续升级。

因此接下来的重点不是重写成另一套玩具，而是：

1. 提炼 runtime 核心
2. 彻底把单一作品资产抽离出去
3. 建立可扩张的资产与作者系统
4. 预埋商业化骨架
